# Block Blast Mod Menu — Android standalone helper

## Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK Platform 35
- Gradle sync through Android Studio (the Gradle wrapper can be generated by Android Studio)

## Build
1. Extract this folder.
2. Open `BlockBlastMod` in Android Studio.
3. Allow Gradle sync to download Android Gradle Plugin 8.7.3.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK output: `app/build/outputs/apk/debug/app-debug.apk`.

Command line after Android Studio has generated the Gradle wrapper:
`./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).

## Use
1. Install the APK.
2. Open it and tap **Floating ON**; grant “Display over other apps”.
3. Enable **Block Blast Mod Menu** under Android Settings > Accessibility.
4. Tap cells in the 10x10 board editor to reproduce the current game board. Blue cells are occupied.
5. Select a piece and press **Find best move**. Gold cells show the recommended placement.
6. For **Auto drag**, enter the board's top-left pixel coordinate, cell size, and the center pixel coordinate of the selected piece in the tray. Save, then press Auto drag. The accessibility service sends one drag gesture from the tray point to the recommended placement's anchor cell. Calibrate carefully; tray locations differ by device and game layout.

## Important implementation scope
This is a standalone helper APK. Android app sandboxing prevents it from silently modifying another app's private memory or granting itself unrestricted permissions. The solver works on the board you enter manually; it does not read Block Blast's internal game state. Auto drag sends one explicit accessibility gesture and requires the owner to enable the service. It does not implement automatic screen recognition, score modification, purchases, or anti-cheat bypass.

The solver evaluates one selected piece at a time, checks legal placements, clears completed rows/columns in its simulation, and prefers line clears. The board editor is a 10x10 approximation; confirm the target game's board geometry before using the tap calibration.
